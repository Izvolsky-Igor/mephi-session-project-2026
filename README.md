# Сессионный проект по курсу «Безопасность GNU/Linux»

**Тема:** Настройка базовых средств защиты ОС GNU/Linux

**Среда выполнения:**
- Операционная система: РЕД ОС 8.0.3 (Server Minimal)
- Виртуализация: QEMU/KVM
- Управление: командная строка GNU/Linux, SSH
- Номер зачётной книжки: **375509**

## Выполненные задачи

| Раздел | Содержание |
|---|---|
| 1. Базовая настройка | Настройка системы и сетевого взаимодействия |
| 2. Управление пакетами | Работа с пакетным менеджером DNF |
| 3. Файловые системы | Создание раздела ext4, настройка автоматического монтирования через `/etc/fstab` |
| 4. Управление сервисами | Установка Nginx, настройка автозапуска и журналирования |
| 5. Управление доступом | Настройка DAC, ACL, Linux Capabilities и SELinux |
| 6. Аутентификация | Ограничение входа через PAM, парольная политика: минимум 12 символов, срок действия 90 дней |
| 7. Тестирование | Создание веб-страницы и проверка доступности через curl |
| 8. Публикация | Подготовка артефактов и размещение результатов на GitHub |

- DAC/ACL: разграничение доступа разработчиков и кураторов.
- PAM: ограничения входа для кураторов.
